# Spring-boot-project-
Spring Boot CRUD API – Learning Project: A hands-on backend practice project where I build real-world REST APIs using Java, Spring Boot, and MySQL. This project helps me understand CRUD operations, clean API architecture, dependency injection, validation, exception handling, and overall backend development essentials.

🚀 Tech Stack

Java 17

Spring Boot

MySQL

Hibernate / JPA

Lombok

Postman

IntelliJ IDEA / VS Code

📘 Key Features

✔ REST API development
✔ CRUD Operations (Create, Read, Update, Delete)
✔ Encapsulation using getter/setter (using Lombok for automation)
✔ Database mapping with JPA (@Entity, @Id, etc.)
✔ Spring Data JPA Repository (Interface-based)
✔ Service Layer + Dependency Injection (@Autowired)
✔ Validation using annotations (@NotNull, @Email, etc.)
✔ Custom Exception Handling
✔ Clean folder structure using Controller → Service → Repository → Entity

🛠 API Testing

All APIs are tested using Postman with proper request & response formats.
